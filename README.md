# MemeDeck

A lightweight, community-driven media library and asset-sharing platform designed to power interactive party games via a high-performance API.

## Architecture

- **`backend/`**: High-performance REST API built with Fastify, TypeScript, Zod, and Swagger (`/docs`).
- **`frontend/`**: Web application built with React, Vite, and TypeScript.
- **`supabase/`**: PostgreSQL migrations, RLS policies, indexes, and media storage bucket.
